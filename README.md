# PetPal — Adopsi Hewan Peliharaan (PWA)

React + Vite + Tailwind + vite-plugin-pwa. Data CRUD disimpan di localStorage sehingga berfungsi offline.

    npm install
    npm run dev       # pengembangan
    npm run build     # produksi (menghasilkan service worker + manifest)
    npm run preview   # uji PWA di http://localhost:4173

Deploy: push ke GitHub lalu import repository di Vercel (preset Vite otomatis).
